# Задачи – Семинар 6: Масиви и функции

Общи изисквания за всички задачи:
- Всяка задача се решава с **функции**, които приемат масива и неговия размер. `main` само чете входа, вика функциите и печата резултата.
- Ако функцията не променя масива, параметърът е `const` (напр. `const int arr[]`).
- Използвайте `const int MAX_SIZE = 100;` (или колкото е указано) и проверявайте, че въведеният размер е в границите.
- Функциите от задача 1 (`readArray`, `printArray`) можете да преизползвате във всички следващи задачи.
- Без `std::vector`, `std::string` и `std::sort` – пишем всичко сами.

### Задача 4: Обръщане на част от масив

Напишете функция `void reverseRange(int arr[], int size, int from, int to)`, която обръща огледално елементите между индексите `from` и `to` включително. Ако индексите са невалидни (`from < 0`, `to >= size` или `from > to`), масивът не се променя.

С помощта на нея напишете и:

- `void reverse(int arr[], int size)` – обръща целия масив;
- `void reverseFirstN(int arr[], int size, int n)` – обръща първите `n` елемента.

```text
reverseRange([4, 5, 6, 7, 8, 9, 0, 1], 8, 2, 5)  ->  [4, 5, 9, 8, 7, 6, 0, 1]
reverseFirstN([1, 2, 3, 4, 5, 6, 7], 7, 4)       ->  [4, 3, 2, 1, 5, 6, 7]
reverse([1, 2, 3])                               ->  [3, 2, 1]
```

<details><summary>Подсказка</summary>

Два индекса – `left = from` и `right = to` – които се движат един към друг, докато `left < right`.
</details>

### Задача 8: Изтриване и вмъкване

Напишете функции, които **променят размера** на масива (размерът се подава по референция):

- `void removeAt(int arr[], int& size, int index)` – премахва елемента на позиция `index`;
- `bool insertAt(int arr[], int& size, int capacity, int index, int value)` – вмъква `value` на позиция `index` (0 ≤ index ≤ size), като измества останалите надясно. Връща `false` и не прави нищо, ако масивът е пълен (`size == capacity`) или индексът е невалиден;
- `void removeAll(int arr[], int& size, int x)` – премахва всички срещания на `x`.

```text
removeAt([33, 1, 23, 8, 54, 5, 1, 6], index = 4)  ->  [33, 1, 23, 8, 5, 1, 6]
insertAt([33, 1, 23, 8], index = 2, value = 100)  ->  [33, 1, 100, 23, 8]
removeAll([1, 2, 1, 3, 1], x = 1)                 ->  [2, 3]
```

<details><summary>Подсказка</summary>

При вмъкване изместването става **отдясно наляво** (от `size - 1` надолу до `index`), иначе ще презапишете елементи. `removeAll` може да се реши с едно обхождане – вижте въпрос 9 от семинара.
</details>

### Задача 16: Линейно зависими масиви

Два масива `a` и `b` с еднаква дължина `n` са **линейно зависими**, ако единият се получава от другия чрез умножение с число: `b = λ·a` или `a = λ·b` (λ е реално число). Напишете функция `bool areLinearlyDependent(const int a[], const int b[], int n)`.

```text
[1, 2, 3, 4, 5] и [2, 4, 6, 8, 10]  ->  yes
[1, 2, 3, 4, 5] и [2, 4, 6, 8, 11]  ->  no
[1, 2, 3] и [0, 0, 0]               ->  yes
```

<details><summary>Подсказка</summary>

За да не работите с дроби, използвайте, че `a` и `b` са линейно зависими точно тогава, когато `a[i] * b[j] == a[j] * b[i]` за всички двойки `i`, `j`. Достатъчно е да сравните всяка двойка с една фиксирана позиция `k`, в която `a[k] != 0` или `b[k] != 0` (ако няма такава – двата масива са нулеви).
</details>

<details><summary>Подсказка</summary>

```text
findElement([2, 3, 17, 8, 1, 9], 6)  ->  2   (17 > (3 + 8) / 2)
```

<details><summary>Подсказка</summary>

Обхождайте отдясно наляво – първият намерен е отговорът. Внимавайте с целочисленото деление: `arr[i] > (arr[i-1] + arr[i+1]) / 2` може да даде грешен отговор при отрицателни числа, напр. за `[-1, -1, -2]`: `(-1 + -2) / 2 = -1` (деленето отрязва към нулата), а реалното средно е `-1.5`. Сравнявайте без деление: `2 * arr[i] > arr[i-1] + arr[i+1]`.
</details>

### Задача 25: Индекс на Хирш

*(изпит 2023/24)*

Да се напише функция `int findIndex(const int arr[], int length)`, която намира най-голямото число `M`, такова че в масива има поне `M` елемента, всеки от които е `≥ M`. Всички елементи на `arr` са неотрицателни.

```text
findIndex([3, 0, 6, 1, 5], 5)  ->  3   (3, 6 и 5 са ≥ 3; няма 4 числа ≥ 4)
findIndex([0, 0], 2)           ->  0
findIndex([10, 10, 10], 3)     ->  3
```

<details><summary>Подсказка</summary>

Параметърът е `const`, затова копирайте масива във временен масив (с размер `MAX_SIZE`) и го сортирайте в **намаляващ** ред. Тогава `M` е най-голямото `i + 1`, за което `sorted[i] >= i + 1`.
</details>
