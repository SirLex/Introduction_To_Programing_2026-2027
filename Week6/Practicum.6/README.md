## Live coding

В началото на практикума ще решим заедно следните задачи:

1. `indexOf`
2. `insertAt`
3. Въвежда се число N и след това два масива с по N елемента, като всички елементи са цифри от 0 до 9. Да се изведе `Yes`, ако вторият масив е пермутация на първия (съдържа същите цифри, същия брой пъти, в произволен ред), и `No` в противен случай.
4. `binarySearch`

Ако в условието не е казано друго, приемете, че входът винаги е коректен и в описания формат. Входът на всяка задача започва с размерите на матрицата – цели числа N и M (1 ≤ N, M ≤ 100), следвани от N реда с по M цели числа – елементите на матрицата. При квадратна матрица се въвежда само N.

Задачите, отбелязани с ⭐, са по-трудни.

## Задачи

### Задача 1

Да се изведе най-малкият елемент на матрицата.

**Вход:**

```
3 4
1 2 3 5
4 5 6 5
7 8 9 5
```

**Изход:**

```
1
```

### Задача 2

Да се изведе сумата на елементите на всеки ред на матрицата, всяка на нов ред.

**Вход:**

```
3 7
7 8 7 4 1 1 0
1 2 0 1 2 1 0
7 5 2 1 0 1 0
```

**Изход:**

```
28
7
16
```

### Задача 3

Да се изведе най-големият елемент във всяка колона на матрицата, разделени с интервал.

**Вход:**

```
3 4
1 8 3 -2
7 2 9 -5
4 6 0 -1
```

**Изход:**

```
7 8 9 -1
```

### Задача 4

Въвежда се квадратна матрица. Да се провери дали всички елементи по главния диагонал са равни на 0.

**Вход:**

```
3
0 5 2
4 0 7
1 3 0
```

**Изход:**

```
true
```

**Вход:**

```
3
0 5 2
4 6 7
1 3 0
```

**Изход:**

```
false
```

### Задача 5

Въвежда се квадратна матрица от естествени числа. Да се провери дали в частта над главния диагонал на матрицата има просто число.

**Вход:**

```
3
4 7 8
10 6 9
15 20 5
```

**Изход:**

```
true
```

**Вход:**

```
3
1 4 6
2 3 8
5 7 9
```

**Изход:**

```
false
```

### Задача 6 ⭐

Въвежда се матрица, в която всеки ред е сортиран във възходящ ред, а първият елемент на всеки ред е по-голям от последния елемент на предходния ред. След матрицата се въвежда цяло число X. Да се провери дали X се среща в матрицата.

Задачата е за упражнение на двоичното търсене. Това е задача от [LeetCode](https://leetcode.com/problems/search-a-2d-matrix/).

**Вход:**

```
3 4
1 3 5 7
10 11 16 20
23 30 34 60
3
```

**Изход:**

```
true
```

**Вход:**

```
3 4
1 3 5 7
10 11 16 20
23 30 34 60
13
```

**Изход:**

```
false
```
