# Увод в програмирането 2026/27 — Семинарни упражнения

Материали за семинарните упражнения по „Увод в програмирането“ (C++), синтезирани от предишните ни репозиторита **Mine2025** и **Ser2025**.

Всяка седмица има собствена директория с два файла:

- **`Seminar.md`** — теория, примери и въпроси за проверка
- **`Tasks.md`** — задачи за упражнение, подредени по трудност

## Учебен план

| :-----: | ---- | --------- |
