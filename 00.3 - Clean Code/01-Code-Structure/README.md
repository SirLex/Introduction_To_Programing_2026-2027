# 1. Структура на кода

За компилатора интервалите, новите редове и табулацията нямат значение. Те са за хората, които четат кода – добре подреденият код показва структурата на програмата още с първия поглед.

## 1.1 Интервали

Оставяйте интервал от двете страни на операторите (`+`, `*`, `=`, `==`, `&&`, `<<` и т.н.) и след всяка запетая. Изключение са `++`, `--`, `!` и минусът пред число – те се пишат слято.

```cpp
// Лошо
int a,b;
int result=a+b*c;
i ++;

// Добре
int a, b;
int result = a + b * c;
i++;
```

## 1.2 Табулация

Всяко ниво на влагане се отмества с една табулация навътре, за да се вижда кой код към кой блок принадлежи.

```cpp
// Лошо
for (int i = 0; i < n; i++) {
cin >> number;
if (number > 0) {
sum += number;
}
}

// Добре
for (int i = 0; i < n; i++) {
    cin >> number;
    if (number > 0) {
        sum += number;
    }
}
```

## 1.3 Къдрави скоби

- Отварящата скоба може да е на същия ред или на нов ред – важното е да спазвате един и същ стил в целия код.
- Когато е на същия ред, оставяйте интервал преди нея: `) {`, а не `){`.
- Слагайте къдрави скоби около тялото на `if`, `else` и циклите, дори когато то е само един ред.

```cpp
// Грешка
if (number > 0)
    cout << "Positive";
    positiveCount++;
```

Въпреки табулацията, `positiveCount++;` не е част от `if` и се изпълнява винаги.

```cpp
// Добре
if (number > 0) {
    cout << "Positive";
    positiveCount++;
}
```

## 1.4 Кръгли скоби

Слагайте скоби там, където помагат на четимостта – при смесени `&&` и `||` и при присвояване на логически израз на `bool`. Не слагайте излишни скоби.

```cpp
// Лошо
if (a > 0 && b > 0 || c == 0) { ... }
bool isPositive = number > 0;
int sum = ((a) + (b));

// Добре
if ((a > 0 && b > 0) || c == 0) { ... }
bool isPositive = (number > 0);
int sum = a + b;
```

## 1.5 Редове

- Всеки израз е на отделен ред.
- Логическите части на програмата (вход, обработка, изход) се разделят с празен ред.
- Никъде не се оставят два или повече празни реда един след друг.

```cpp
int main() {
    int a, b;
    cin >> a >> b;

    int sum = a + b;
    int product = a * b;

    cout << sum << endl;
    cout << product << endl;
}
```

## 1.6 Автоматично форматиране

Във Visual Studio **Ctrl+K, Ctrl+D** подрежда целия файл – табулация, интервали и място на скобите. Това обаче не замества правилата по-горе: форматирането не добавя липсващи къдрави скоби и празни редове.
