# Clean Code

## Защо е важно да пишем чист код?

Кодът се чете много повече пъти, отколкото се пише. Чете го асистентът, който проверява домашното ви, колегата, с когото работите по проект, и най-често самите вие след седмица, когато вече не помните какво сте имали предвид.

Чистият код е код, който се разбира лесно от първия прочит. Той:

- **се чете по-бързо** – не се налага да разгадавате какво прави всеки ред;
- **съдържа по-малко грешки** – когато логиката е ясна, грешките се виждат веднага;
- **се променя по-лесно** – добавянето на нова функционалност не чупи старата;
- **се преизползва** – добре написаната функция може да се използва отново, вместо кодът да се копира.

Програма, която работи, но никой не може да разбере, е трудна за поправяне и надграждане. Затова работодателите търсят програмисти, които пишат не просто работещ, а чист и добре структуриран код. Свикнете с добрите практики още от самото начало.
