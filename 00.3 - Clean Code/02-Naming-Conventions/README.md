# 2. Именуване

Добре избраното име казва какво съдържа променливата или какво прави функцията, без да се налага да се чете останалият код.

## 2.1 Смислени имена

Името трябва да описва какво съдържа променливата. Предпочитайте цели думи пред съкращения, освен ако съкращението не е общоизвестно.

```cpp
// Лошо
int a, b, c;
int cnt;

// Добре
int width, height, area;
int count;
```

Изключение са броячите в циклите – за тях `i`, `j` и `k` са общоприети.

## 2.2 Английски имена

Имената се пишат на английски, без транслитерация от български.

```cpp
// Лошо
int suma;
int broi;

// Добре
int sum;
int count;
```

## 2.3 camelCase

Имената на променливи и функции започват с малка буква, а всяка следваща дума – с главна, без долни черти.

```cpp
// Лошо
int positivecount;
int Positive_Count;

// Добре
int positiveCount;
```

## 2.4 Имена на `bool` и функции

- Имената на `bool` звучат като въпрос с отговор да или не: `isPrime`, `hasNegative`, `isValid`.
- Имената на функции започват с глагол, който казва какво правят: `printNumber`, `countDigits`, `calculateSum`.

## 2.5 Константи и магически числа

Число в кода, за което не е ясно откъде идва, се нарича „магическо число“. Изнесете го в константа с говорещо име. Имената на константите се пишат с главни букви и долни черти между думите.

```cpp
// Лошо
int hours = minutes / 60;

// Добре
const int MINUTES_IN_HOUR = 60;
int hours = minutes / MINUTES_IN_HOUR;
```

Така числото има име, което обяснява смисъла му, а ако трябва да се промени, това става само на едно място.
