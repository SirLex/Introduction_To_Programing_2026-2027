# 3. Променливи

Всяка променлива трябва да е видима само там, където е нужна. Колкото по-малка е частта от кода, в която може да се използва и промени, толкова по-лесно се проследява какво се случва с нея.

## 3.1 Деклариране близо до използването

Декларирайте променливата непосредствено преди мястото, където ще я използвате, а не всички в началото на `main`. Броячът на цикъл се декларира в самия `for`.

```cpp
// Лошо
int main() {
    int n, i, number, sum;
    cin >> n;
    sum = 0;
    for (i = 0; i < n; i++) {
        cin >> number;
        sum += number;
    }
    cout << sum;
}

// Добре
int main() {
    int n;
    cin >> n;

    int sum = 0;
    for (int i = 0; i < n; i++) {
        int number;
        cin >> number;
        sum += number;
    }

    cout << sum;
}
```

## 3.2 Инициализиране

Давайте начална стойност на всяка променлива, която се използва, преди да ѝ се присвои нещо. Неинициализираната променлива съдържа случайна стойност.

```cpp
// Лошо
int sum;
sum += number; // sum съдържа случайна стойност

// Добре
int sum = 0;
sum += number;
```

## 3.3 Без глобални променливи

Глобалната променлива се декларира извън функциите и може да се използва и променя навсякъде в програмата. Когато стойността ѝ е грешна, трудно се открива кое място я е променило. Декларирайте променливите вътре във функцията, в която са нужни, и подавайте стойностите им на други функции чрез параметри.

```cpp
// Лошо
int sum = 0;

int main() {
    ...
    sum += number;
}

// Добре
int main() {
    int sum = 0;
    ...
    sum += number;
}
```
