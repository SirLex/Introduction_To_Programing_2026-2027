# 4. Условия и цикли

## 4.1 Интервали при скобите

Между `if`, `for`, `while` или `switch` и отварящата скоба се оставя интервал. От вътрешната страна на скобите интервали няма.

```cpp
// Лошо
if(number > 0)
while ( n > 0 )

// Добре
if (number > 0)
while (n > 0)
```

## 4.2 Опростяване на условията

- Не сравнявайте `bool` с `true` или `false` – стойността му вече е условие.
- Когато `if` само присвоява или връща `true` или `false`, присвоете или върнете директно условието.

```cpp
// Лошо
if (isPrime == true) { ... }

if (number % 2 == 0) {
    isEven = true;
} else {
    isEven = false;
}

if (number % 2 == 0) {
    return true;
} else {
    return false;
}

// Добре
if (isPrime) { ... }

isEven = (number % 2 == 0);

return (number % 2 == 0);
```

## 4.3 Без дълбоко влагане

Няколко вложени `if` един в друг правят кода труден за следене. Често те могат да се обединят в едно условие или да се избегнат с `continue`.

```cpp
// Лошо
for (int i = 1; i <= n; i++) {
    if (i % 2 == 0) {
        if (i % 3 == 0) {
            cout << i << endl;
        }
    }
}

// Добре
for (int i = 1; i <= n; i++) {
    if (i % 2 == 0 && i % 3 == 0) {
        cout << i << endl;
    }
}
```

## 4.4 `switch`

- Без `break` изпълнението продължава в следващия `case` („пропадане“). Слагайте `break`, освен ако пропадането не е нарочно.
- Пропадането е удобно, когато няколко стойности трябва да се обработят по един и същ начин.
- Добавяйте `default` за стойностите, които не са покрити от нито един `case`.

```cpp
switch (operation) {
    case '+':
        cout << a + b;
        break;
    case 'x':
    case '*': // 'x' пропада тук и двата символа означават умножение
        cout << a * b;
        break;
    default:
        cout << "Invalid operation";
        break;
}
```

## 4.5 Тернарен оператор

Използвайте тернарния оператор само за прости случаи с два варианта. Вложени тернарни оператори се заменят с `if`.

```cpp
// Добре
int maxValue = (a > b) ? a : b;

// Лошо
cout << (n > 0 ? "Positive" : n < 0 ? "Negative" : "Zero");
```
