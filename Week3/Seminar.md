# Семинар 3: Оператори за цикъл и условни оператори – затвърждаване. Switch. Break и Continue. Тернарен оператор.


### 1. Преговор: `if` / `else if` / `else`

Условната конструкция (conditional statement) изпълнява различен код в зависимост от стойността на булев израз.

```cpp
#include <iostream>

int main() {
    int n;
    std::cin >> n;

    if (n < 100) {
        std::cout << "Less than 100\n";
    } else if (n <= 200) {        // тук вече знаем, че n >= 100
        std::cout << "Between 100 and 200\n";
    } else {
        std::cout << "Greater than 200\n";
    }
    return 0;
}
```

Условията се проверяват **отгоре надолу** и се изпълнява само **първият** клон, чието условие е истина. `else` е незадължителен.

> [!WARNING]
> **Три класически грешки:**
> ```cpp
> if (a = 5)  { /* ... */ }   // присвояване, НЕ сравнение! Изразът е 5 -> true
> if (a == 0); { /* ... */ }  // ';' завършва if-а -> блокът { } се изпълнява ВИНАГИ
> if (a, b - 2 * a) { /* ... */ } // операторът ',' връща само последния израз
> ```
> Пишете `==` за сравнение, не слагайте `;` след `)` на `if`/`while`/`for` и винаги ползвайте `{ }`.

> [!NOTE]
> Всяка числова стойност, различна от `0`, се преобразува до `true`, а `0` – до `false`. Затова `if (n)` е същото като `if (n != 0)`.

### 2. `switch`

`switch` избира кой код да се изпълни според **стойността** на един израз. Удобен е, когато сравняваме една променлива с много конкретни стойности.

```cpp
switch (<израз>) {
    case <константа1>:
        <действия>
        break;
    case <константа2>:
        <действия>
        break;
    default:            // незадължителен – ако няма съвпадение
        <действия>
        break;
}
```

```cpp
#include <iostream>

int main() {
    int day;
    std::cin >> day;

    switch (day) {
        case 1: std::cout << "Monday\n";    break;
        case 2: std::cout << "Tuesday\n";   break;
        case 3: std::cout << "Wednesday\n"; break;
        case 4: std::cout << "Thursday\n";  break;
        case 5: std::cout << "Friday\n";    break;
        case 6: std::cout << "Saturday\n";  break;
        case 7: std::cout << "Sunday\n";    break;
        default: std::cout << "Invalid day!\n"; break;
    }
    return 0;
}
```

**Правила:**
- Изразът трябва да е от **целочислен** тип: `int`, `char`, `bool`, `short`, `long`, `unsigned`, изброим тип (enum). **`double` и `float` НЕ са позволени.**
- Стойностите след `case` трябва да са **константи, известни по време на компилация** (литерали, `const` променливи с константна стойност), и да са **различни**.
- `default` може да е на произволно място (не само последен), но по конвенция се пише накрая.
- `break` прекратява изпълнението на `switch`.

#### Fall-through („пропадане“)

Ако в даден `case` няма `break`, изпълнението **продължава в следващия `case`**, без да проверява стойността му – докато не срещне `break` или края на `switch`.

```cpp
int x = 1;
switch (x) {
    case 1: std::cout << "A";
    case 2: std::cout << "B";
    default: std::cout << "C";
}
// Отпечатва: ABC
```

Fall-through е полезен, когато няколко стойности трябва да имат **едно и също** поведение:

```cpp
char c;
std::cin >> c;
switch (c) {
    case 'a': case 'e': case 'i': case 'o': case 'u':
        std::cout << "vowel\n";
        break;
    default:
        std::cout << "consonant\n";
        break;
}
```

> [!TIP]
> Ако пропадането е **умишлено**, в C++17 може да го отбележите с `[[fallthrough]];`. Така компилаторът не предупреждава, а читателят знае, че не сте забравили `break`.
> ```cpp
> case 2:
>     std::cout << "two\n";
>     [[fallthrough]];
> case 3:
>     std::cout << "three\n";
>     break;
> ```

> [!WARNING]
> Ако декларирате и инициализирате променлива в `case`, оградете го с `{ }` – иначе кодът не се компилира („jump to case label crosses initialization“).
> ```cpp
> case 1: {
>     int t = 10;
>     std::cout << t;
>     break;
> }
> ```

**`switch` или `if`?** `switch` работи само с **равенство** на целочислени стойности. За интервали (`x < 10`), реални числа или сложни условия – `if`/`else if`.

### 3. Тернарен оператор (conditional operator)

```cpp
<условие> ? <израз1> : <израз2>
```

Ако условието е истина, резултатът е `<израз1>`, иначе – `<израз2>`. Това е **израз** (има стойност), а не конструкция – затова може да се използва в присвояване или в `std::cout`.

```cpp
int a = 3, b = 7;
int maxValue = (a > b) ? a : b;              // 7
std::cout << (n % 2 == 0 ? "even" : "odd");
```

Пример от семинара („99 Bottles of Beer“) – правилна форма за единствено/множествено число:

```cpp
for (int i = 99; i >= 1; i--) {
    std::cout << i << " bottle" << (i == 1 ? "" : "s") << " of beer on the wall\n";
}
```

Тернарните оператори могат да се влагат (асоциативен е **отдясно наляво**):

```cpp
int x = 5;
int category = x > 3 ? (x < 10 ? 1 : 2) : 3;   // 1
```

> [!WARNING]
> Тернарният оператор е с **много нисък приоритет** – по-нисък от `<<`.
> ```cpp
> std::cout << (a > b) ? a : b;   // ГРЕШНО: изпълнява се (std::cout << (a > b)) ? a : b;
>                                  // отпечатва 0 или 1!
> std::cout << ((a > b) ? a : b); // правилно
> ```
> Винаги слагайте скоби около целия тернарен израз в `std::cout`.

> [!TIP]
> Използвайте `?:` за **кратък избор между две стойности**. Ако вложите повече от едно ниво или клоновете имат странични ефекти – пишете `if`/`else`, за да е четимо.

### 4. Цикли

**Цикъл** (loop) е конструкция, която изпълнява даден код многократно, докато е изпълнено някакво условие. Всяко изпълнение на тялото се нарича **итерация** (iteration).

- **Индуктивен цикличен процес** – броят на повторенията е известен предварително (напр. „отпечатай числата от 1 до n“) – обикновено `for`.
- **Итеративен цикличен процес** – броят на повторенията **не** е известен предварително (напр. „чети числа, докато не въведат 0“) – обикновено `while` / `do-while`.

#### 4.1. `while`

```cpp
while (<условие>) {
    // тяло
}
```

1. Изчислява се условието.
2. Ако е `false` – цикълът приключва (тялото може да не се изпълни **нито веднъж**).
3. Ако е `true` – изпълнява се тялото и се връщаме на стъпка 1.

```cpp
// Сумира числа, докато не се въведе 0
int sum = 0;
int x;
std::cin >> x;
while (x != 0) {
    sum += x;
    std::cin >> x;
}
std::cout << sum;
```

#### 4.2. `do-while`

```cpp
do {
    // тяло
} while (<условие>);   // обърнете внимание на ';'
```

Тялото се изпълнява **поне веднъж**, а условието се проверява **след** него.

```cpp
int i = 5;

while (i < 5) {           // не влиза изобщо
    std::cout << i << ' ';
    i++;
}

do {                      // отпечатва 5
    std::cout << i << ' ';
    i++;
} while (i < 5);
```

Типичен пример – валидиране на вход:

```cpp
int n;
do {
    std::cout << "Enter n in [1, 7]: ";
    std::cin >> n;
} while (n < 1 || n > 7);
```

> [!WARNING]
> Променлива, декларирана **в тялото** на `do-while`, **не се вижда** в условието `while (...)` – то е извън блока `{ }`.

#### 4.3. `for`

```cpp
for (<инициализация>; <условие>; <промяна>) {
    // тяло
}
```

1. `<инициализация>` се изпълнява **веднъж** в началото.
2. Проверява се `<условие>`; ако е `false` – край.
3. Изпълнява се тялото.
4. Изпълнява се `<промяна>` (update) и се връщаме на стъпка 2.

```cpp
// Сумата на четните числа в [2; n]
int n;
std::cin >> n;
int sum = 0;
for (int i = 2; i <= n; i += 2) {
    sum += i;
}
std::cout << sum;
```

`for` е еквивалентен на:

```cpp
{
    <инициализация>;
    while (<условие>) {
        // тяло
        <промяна>;
    }
}
```

(с една разлика – `continue` във `for` **все пак изпълнява** `<промяна>`, вижте по-долу).

> [!NOTE]
> Променлива, декларирана в инициализацията (`for (int i = 0; ...)`), съществува **само в цикъла**. След него `i` не е достъпна.

**Нестандартни (но валидни) форми на `for`:**

```cpp
for (;;) { /* безкраен цикъл – излизаме с break */ }

for (int i = 0, j = 10; i < j; i++, j--) {     // две променливи
    std::cout << i << " " << j << "\n";         // 0 10, 1 9, 2 8, 3 7, 4 6
}

int sum = 0;
for (int i = 1; i <= 5; sum += i++);            // празно тяло: sum = 15
```

#### 4.4. Кой цикъл да изберем?

| Ситуация | Цикъл |
|---|---|
| Знаем броя повторения / обхождаме интервал | `for` |
| Повтаряме, докато е изпълнено условие (може и 0 пъти) | `while` |
| Тялото трябва да се изпълни поне веднъж (меню, валидиране на вход) | `do-while` |

### 5. `break` и `continue` (jump statements)

- **`break`** – незабавно **прекратява** най-вътрешния цикъл (или `switch`), в който се намира.
- **`continue`** – прекратява **текущата итерация** и преминава към следващата (при `for` – към `<промяна>`, при `while`/`do-while` – към проверката на условието).

```cpp
// Отпечатва нечетните числа от 1 до 20, но спира при първото > 15
for (int i = 1; i <= 20; i++) {
    if (i % 2 == 0) {
        continue;   // пропусни четните
    }
    if (i > 15) {
        break;      // излез от цикъла
    }
    std::cout << i << ' ';   // 1 3 5 7 9 11 13 15
}
```

> [!WARNING]
> **`continue` в `while` може да предизвика безкраен цикъл**, ако промяната на брояча е след него:
> ```cpp
> int i = 0;
> while (i < 10) {
>     if (i == 5) continue;  // i никога не става 6 -> безкраен цикъл!
>     i++;
> }
> ```

> [!NOTE]
> `break` излиза само от **най-вътрешния** цикъл/`switch`. Ако `switch` е вътре в цикъл, `break` в `case` излиза само от `switch`, не от цикъла!
> ```cpp
> for (int i = 0; i < 3; i++) {
>     switch (i) {
>         case 1: std::cout << "one "; break;   // излиза от switch
>         default: std::cout << i << ' ';
>     }
> }
> // Отпечатва: 0 one 2
> ```

### 6. Вложени цикли (nested loops)

Цикъл в тялото на друг цикъл. За всяка итерация на външния цикъл вътрешният се изпълнява **изцяло**.

```cpp
#include <iostream>

int main() {
    int rows, cols;
    std::cin >> rows >> cols;

    for (int i = 0; i < rows; i++) {        // за всеки ред
        for (int j = 0; j < cols; j++) {    // за всяка колона
            std::cout << '*';
        }
        std::cout << '\n';                  // нов ред след всеки ред
    }
    return 0;
}
```

Таблица за умножение (вътрешният цикъл зависи от външния – триъгълна форма):

```cpp
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        std::cout << j << "*" << i << "=" << i * j << '\t';
    }
    std::cout << '\n';
}
```

> [!TIP]
> При рисуване на фигури първо си направете **таблица**: за ред `i` – колко интервала, колко символа? Намерете формулата спрямо `i` и `n`, после пишете цикъла.

> [!NOTE]
> За да излезете от **няколко** вложени цикъла наведнъж, използвайте булев флаг (`bool found = false;`), който проверявате във външното условие.

### 7. Приоритет на операторите (operator precedence)

Подредени от **най-висок** към **най-нисък** приоритет (частична таблица):

| Приоритет | Оператори | Асоциативност |
|---|---|---|
| 1 | `a++` `a--` (постфиксни) | → |
| 2 | `++a` `--a` (префиксни), `!`, унарни `+` `-` | ← |
| 3 | `*` `/` `%` | → |
| 4 | `+` `-` | → |
| 5 | `<<` `>>` | → |
| 6 | `<` `<=` `>` `>=` | → |
| 7 | `==` `!=` | → |
| 8 | `&&` | → |
| 9 | `\|\|` | → |
| 10 | `?:`, `=`, `+=`, `-=`, `*=`, ... | ← |
| 11 | `,` (оператор запетая) | → |

```cpp
int r = 1 + 2 * 3 > 6 && 4 % 3 == 1;   // ((1 + (2*3)) > 6) && ((4 % 3) == 1) -> 1
```

- **Short-circuit:** `&&` спира при първия `false`, `||` – при първия `true`. Затова `(b != 0 && a / b > 2)` е безопасно.
- **Оператор запетая:** оценява всички изрази отляво надясно и връща **последния**.

> [!TIP]
> Когато не сте сигурни – **сложете скоби**. Те не струват нищо и правят кода четим.

### 8. Undefined behaviour и редът на изчисление

**Недефинирано поведение** (undefined behaviour, UB) – стандартът не казва какво трябва да стане; програмата може да изведе каквото и да е, различно на различни компилатори, или да „работи“ случайно.

При изчисление на израз редът, в който се оценяват **операндите** на повечето оператори (`+`, `*`, `<`, ...), **не е определен**. Ако една променлива се **променя** и в същия израз се **чете/променя** отново без гарантиран ред – това е UB:

```cpp
int i = 1;
int r = i++ + ++i;     // UB! (clang: "multiple unsequenced modifications to 'i'")
a = ++a + a++;         // UB!
std::cout << i << i++; // преди C++17 – UB; от C++17 << се оценява отляво надясно
```

> [!NOTE]
> **C++17 промени някои правила.** Следните изрази бяха UB в по-старите стандарти, но **в C++17 са добре дефинирани**, защото дясната страна на `=` / `+=` / `*=` се изчислява изцяло **преди** лявата:
> ```cpp
> int a = 5;
> a = a++;        // C++17: a остава 5
> a = 5;
> a *= a += 3;    // C++17: първо a += 3 -> 8, после a *= 8 -> 64
> a = 5;
> a += (a = 10);  // C++17: първо a = 10, после a += 10 -> 20
> ```
> Въпреки това **не пишете такъв код** – труден е за четене и зависи от версията на стандарта.

> [!WARNING]
> Правило: **в един израз променяйте дадена променлива най-много веднъж и не я четете отново в същия израз.** Компилирайте с `-Wall` – clang и gcc предупреждават за много от тези случаи.

### 9. Чести грешки с цикли

```cpp
for (unsigned i = 10; i >= 0; i--) { }   // безкраен: unsigned винаги е >= 0 (0 - 1 -> 4294967295)

for (int i = 0; i < 5; i++); { std::cout << "hi"; }  // ';' -> празно тяло, "hi" се печата веднъж

int i = 0;
while (i < 10) { std::cout << i; }        // забравено i++ -> безкраен цикъл

for (double x = 0; x != 1.0; x += 0.1) { } // 0.1 не се представя точно -> x никога не е точно 1.0
```

> [!TIP]
> Off-by-one грешки: проверете **първата** и **последната** итерация на ръка – `i < n` или `i <= n`? Започваме от 0 или 1?

## Какво ще отпечата?

**1.** Какво ще отпечата?
```cpp
int x = 3;
switch (x) {
    default:
        std::cout << "no match -> ";
    case 1:
        std::cout << "one-or-after-default\n";
        break;
    case 2:
        std::cout << "two\n";
        break;
}
```
<details><summary>Отговор</summary>

`no match -> one-or-after-default`

Няма `case 3`, затова се влиза в `default`. В него няма `break` и изпълнението „пропада“ в `case 1`, докато не срещне `break`. Мястото на `default` не е задължително накрая.
</details>

**2.** Какво ще отпечата при `x = 2`? А при `x = 5`?
```cpp
switch (x) {
    case 1: std::cout << "A";
    case 2: std::cout << "B";
    case 3: std::cout << "C"; break;
    default: std::cout << "D";
}
```
<details><summary>Отговор</summary>

При `x = 2`: `BC` (пропадане от `case 2` в `case 3`, там има `break`). При `x = 5`: `D`.
</details>

**3.** Какво ще отпечата при `a = 3`, `b = 7`?
```cpp
std::cout << (a > b) ? a : b;
```
<details><summary>Отговор</summary>

`0`. Операторът `<<` е с по-висок приоритет от `?:`, т.е. изразът е `(std::cout << (a > b)) ? a : b;` – отпечатва се стойността на `a > b` (false → `0`), а резултатът на `?:` се изхвърля. Правилно: `std::cout << ((a > b) ? a : b);`
</details>

**4.** Какво ще отпечата?
```cpp
int a = 2;
int b = 4;
int c = a * b;
std::cout << (++a) * c + (b--) / 3 + c;
```
<details><summary>Отговор</summary>

`33`. `c = 8`; `++a` → `3`, `3 * 8 = 24`; `b--` връща старата стойност `4`, `4 / 3 = 1` (целочислено деление); `24 + 1 + 8 = 33`. Тук няма UB – всяка променлива се променя само веднъж.
</details>

**5.** Какво ще отпечата?
```cpp
for (int i = 0, j = 10; i < j; i++, j--)
    std::cout << i << " " << j << "\n";
```
<details><summary>Отговор</summary>

```text
0 10
1 9
2 8
3 7
4 6
```
При `i = 5, j = 5` условието `i < j` е false.
</details>

**6.** Какво ще отпечата?
```cpp
int a = 10;
while (a) {
    a++;
    std::cout << a-- << " ";
    a--;
}
```
<details><summary>Отговор</summary>

`11 10 9 8 7 6 5 4 3 2`. На всяка итерация `a` се увеличава с 1, отпечатва се (постфиксно `a--` печата старата стойност), после общо се намаля с 2. Т.е. за всяка итерация `a` намалява с 1 и се печата `a + 1`. Цикълът спира, когато `a` стане `0`.
</details>

**7.** Каква е разликата между двата фрагмента?
```cpp
int a = 0;
while (a) {
    std::cout << "a";
}
```
```cpp
int a = 0;
do {
    std::cout << "a";
} while (a);
```
<details><summary>Отговор</summary>

Първият не отпечатва нищо (условието е false още преди първата итерация). Вторият отпечатва `a` веднъж – тялото на `do-while` се изпълнява поне веднъж.
</details>

**8.** Какво ще се случи?
```cpp
for (unsigned i = 10; i >= 0; i--) {
    std::cout << i << " ";
}
```
<details><summary>Отговор</summary>

Безкраен цикъл. `unsigned` никога не е отрицателно – след `0` идва `4294967295` (препълване/wrap-around), така че `i >= 0` е винаги истина. Отпечатва `10 9 ... 1 0 4294967295 4294967294 ...`.
</details>

**9.** Ще се компилира ли?
```cpp
do {
    int y = 1;
    std::cout << y++ << " ";
} while (y <= 10);
```
<details><summary>Отговор</summary>

**Не.** `y` е декларирана в тялото на цикъла и не е видима в условието `while (y <= 10)` – „use of undeclared identifier 'y'“.
</details>

**10.** Какво ще се случи?
```cpp
for (int i = 0; i < 10; ) {
    i = i++;
    std::cout << "Hello World";
}
```
<details><summary>Отговор</summary>

Безкраен цикъл, отпечатващ `Hello World`. В C++17 `i = i++` е дефинирано: `i++` връща `0` (и увеличава `i` на `1`), след това присвояването записва `0` обратно в `i`. Значи `i` винаги е `0`. (Преди C++17 това е UB.)
</details>

**11.** Какво ще отпечата?
```cpp
int s = 0;
for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) continue;
    if (i == 8) break;
    s += i;
}
std::cout << s;
```
<details><summary>Отговор</summary>

`19`. Събират се `1 + 2 + 4 + 5 + 7` (пропускат се 3 и 6, при `i = 8` цикълът спира).
</details>

**12.** Какво ще отпечата?
```cpp
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) break;
        std::cout << i << j << " ";
    }
}
```
<details><summary>Отговор</summary>

`00 10 20`. `break` прекъсва само вътрешния цикъл – външният продължава.
</details>

**13.** Ще се компилира ли? Ако да, какво ще отпечата?
```cpp
int i = 10;
while (i = 6 || i = 10) {
    std::cout << i;
}
```
<details><summary>Отговор</summary>

**Не се компилира.** Заради приоритета (`||` е преди `=`, а `=` е дясноасоциативен) изразът се чете като `i = ((6 || i) = 10)` – опит за присвояване на временна стойност (`6 || i` не е lvalue).
</details>

**14.** Какво ще отпечата?
```cpp
while (true) {
    int i = 10;
    while ((i = 6) || (i = 10)) {
        if (i == 0) break;
        if (i == 10) continue;
        std::cout << i-- << std::endl;
        std::cout << --i << std::endl;
    }
    break;
}
```
А ако условието е `((i == 6) || (i == 10))`?
<details><summary>Отговор</summary>

С `=`: безкраен цикъл, отпечатващ `6` и `4` отново и отново – в началото на всяка итерация `i = 6` (присвояване, стойност 6 → true), после `i--` печата 6, `--i` печата 4.

С `==`: безкраен цикъл **без изход** – `i == 10`, условието е истина, `continue` пропуска всичко, а `i` никога не се променя.
</details>

**15.** Какво ще отпечата (първите и последните редове)?
```cpp
unsigned short i = 10;
while ((i == 6) || (i != 6)) {
    if (i == 11) break;
    if (i == 10) i++;
    std::cout << i-- << std::endl;
    std::cout << --i << std::endl;
}
```
<details><summary>Отговор</summary>

Условието е винаги истина. Първа итерация: `i` става 11, печата `11`, после `9`. След това `i` намалява с 2 на итерация през нечетните числа: `9 7 7 5 5 3 3 1 1 65535` – тук `--i` от 0 прави wrap-around до 65535 (`unsigned short` е 16-битово: [0, 65535]). Продължава `65535 65533 65533 ... 13 13 11` и при `i == 11` – `break`.

Изход: `11 9 9 7 7 5 5 3 3 1 1 65535 65535 65533 ... 15 13 13 11` (по един на ред, 65536 реда общо).
</details>

**16.** Кои от следните изрази са undefined behaviour в C++17?
```cpp
int a = 5;
a = a++;          // (1)
a *= a += 3;      // (2)
a = ++a + a++;    // (3)
a += (a = 10);    // (4)
int r = a++ + ++a; // (5)
```
<details><summary>Отговор</summary>

UB са **(3)** и **(5)** – двата операнда на `+` не са подредени (unsequenced) и двата променят `a`.

(1), (2) и (4) са дефинирани от C++17 нататък (дясната страна на присвояването се изчислява преди лявата): (1) → `a` е непроменено; (2) с `a = 5` → `64`; (4) → `20`. Преди C++17 и те бяха UB. Във всички случаи – избягвайте такъв код.
</details>

**17.** Какво ще отпечата?
```cpp
int x = 5;
int y = x > 3 ? x < 10 ? 1 : 2 : 3;
std::cout << y;
```
<details><summary>Отговор</summary>

`1`. Тернарният оператор е дясноасоциативен: `x > 3 ? (x < 10 ? 1 : 2) : 3`.
</details>

**18.** Какво ще отпечата?
```cpp
int k = 0;
for (int i = 0; i < 5; i++); {
    k++;
}
std::cout << k;
```
<details><summary>Отговор</summary>

`1`. `;` след `for (...)` е празното тяло на цикъла; блокът `{ k++; }` е отделен и се изпълнява веднъж.
</details>
