## Задачи

### Задача 1

Да се напише програма, която извежда следния текст на екрана:

```
Oh what
a happy day!
Oh yes,
what a happy day!
```

### Задача 2

Въвеждат се две цели числа a и b. Да се разменят стойностите им и да се изведат.

**Вход:**

```
2005 2007
```

**Изход:**

```
a = 2007
b = 2005
```

- След като решите задачата по стандартния начин, опитайте да я решите, без да създавате нова променлива.

### Задача 15

Въвеждат се три положителни (не непременно цели) числа – страни на триъгълник. Да се изведат периметърът и лицето му. Приемете, че такъв триъгълник винаги съществува.

**Вход:**

```
3 4 5
```

**Изход:**

```
Area = 6, Perimeter = 12
```

<details>
<summary>Помощ</summary>

</details>

### Задача 17

Двама състезатели се движат по една и съща писта в една и съща посока, но с различни скорости. По-бързият тръгва зад по-бавния, на известно разстояние от него. Програмата приема скоростта на по-бавния, скоростта на по-бързия (в km/h) и разстоянието между тях в началния момент (в km). Да се изчисли след колко часа по-бързият ще настигне по-бавния.

**Вход:**

```
10 12 4
```

**Изход:**

```
2
```
