# Семинар 1: Увод. Среди за разработка. Създаване на проект. Типове данни. Аритметични операции. Вход и изход

## 1. Основни понятия

- **Алгоритъм** (algorithm) – крайна последователност от ясно определени стъпки за решаване на даден проблем.
- **Програма** (program) – редица от инструкции, които компютърът изпълнява, за да реши конкретна задача. Програмата е алгоритъм, записан на език за програмиране.
- **Език за програмиране** (programming language) – изкуствен език със строги правила (синтаксис), чрез който описваме инструкции за компютъра. C++ е компилируем език с общо предназначение.
- **Компилатор** (compiler) – програма, която превежда изходния код (source code) от език като C++ до машинен код, разбираем за процесора.
- **Среда за разработка** (IDE – Integrated Development Environment) – приложение, което обединява редактор на код, компилатор, дебъгер (debugger) и инструменти за управление на проекти.

> [!NOTE]
> **Защо C++?** Езикът е бърз, дава контрол върху паметта и показва „какво се случва под капака“. Голяма част от съвременните езици (Java, C#, JavaScript) заимстват синтаксиса му, така че наученото тук се пренася лесно.

### От изходен код до изпълним файл

```text
 main.cpp ──► [препроцесор] ──► [компилатор] ──► main.o ──► [линкер] ──► main / main.exe
 (код)        #include и др.    превод до          (обектен     свързва с         (изпълним
                                машинен код         файл)       библиотеките       файл)
```

1. **Препроцесор** (preprocessor) – обработва редовете, започващи с `#` (напр. `#include` буквално вмъква съдържанието на друг файл).
2. **Компилатор** – проверява синтаксиса и типовете и превежда кода до обектен файл. Тук получаваме **грешки при компилация** (compile-time errors).
3. **Линкер** (linker) – свързва обектните файлове и стандартната библиотека в един изпълним файл.
4. **Изпълнение** – по време на работа може да възникнат **грешки по време на изпълнение** (runtime errors), напр. деление на нула.

2. *Create a new project* → **Console App** (C++) → име и папка → *Create*.
3. Пишем кода в генерирания `.cpp` файл.

> [!TIP]
> В Visual Studio избягвайте имена на проекти/папки с кирилица и интервали – спестява странни грешки при компилация.

### VS Code + g++ / clang++

1. Инсталирайте компилатор:
   - **Windows** – [MSYS2](https://www.msys2.org/) и пакета `mingw-w64-ucrt-x86_64-gcc` (после добавете `C:\msys64\ucrt64\bin` в `PATH`).
   - **macOS** – `xcode-select --install` (инсталира `clang++`, достъпен и като `g++`).
   - **Linux** – `sudo apt install build-essential` (или аналог за дистрибуцията).
2. Проверка в терминал: `g++ --version`.
3. В VS Code инсталирайте разширението **C/C++** (Microsoft); по желание **Code Runner**.
4. „Проект“ тук е просто папка: *File → Open Folder*, създайте `main.cpp`.
5. Компилирайте и стартирайте от вградения терминал (**Ctrl + `**):

```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o main   # компилиране
./main                                          # стартиране (на Windows: .\main.exe)
```

| Флаг | Значение |
| :--- | :------- |
| `-std=c++17` | използвай стандарта C++17 |
| `-Wall -Wextra` | включи (почти) всички предупреждения (warnings) – **винаги ги ползвайте** |
| `-o main` | име на изпълнимия файл (по подразбиране `a.out` / `a.exe`) |

## 3. Структура на C++ програма

```cpp
#include <iostream> // препроцесорна директива: вмъква библиотеката за вход/изход

// Едноредов коментар
/* Многоредов
   коментар */

int main() {                              // входна точка на програмата
    std::cout << "Hello, World!" << '\n'; // всяка инструкция завършва с ;
    return 0;                             // 0 = програмата е завършила успешно
}
```

- Изпълнението **винаги** започва от функцията `main`. Тя е точно една в програмата.
- Тялото на `main` е **блок** (block) – заграден с `{ }`.
- Всяка инструкция (statement) завършва с `;`.
- `return 0;` в `main` може да се пропусне – компилаторът го добавя автоматично (само за `main`!).
- C++ различава малки и главни букви (case-sensitive): `Main`, `MAIN` и `main` са различни имена.

### `#include`

- `#include <iostream>` – системна/стандартна библиотека; търси се в директориите на компилатора.
- `#include "myHeader.h"` – собствен файл; търси се първо в папката на проекта (ще ги ползваме по-късно).

### `std::` и `using namespace std;`

Стандартната библиотека е в **пространството от имена** (namespace) `std`. Затова пишем `std::cout`, `std::cin`.

```cpp
#include <iostream>
using namespace std; // "внася" всички имена от std

int main() {
    cout << "Hello!\n"; // вече може без std::
}
```

> [!NOTE]
> В материалите ще пишем `std::`. `using namespace std;` е допустимо в малки учебни програми, но в по-големи проекти внася стотици имена и може да доведе до конфликти. Компромис е да внесем само това, което ползваме: `using std::cout; using std::cin;`.

## 4. Стандартен вход и изход

Входът и изходът в C++ се извършват чрез **потоци** (streams) – последователности от байтове:

- **входен поток** – от устройство (клавиатура) към паметта на програмата → `std::cin` (character input), оператор `>>`;
- **изходен поток** – от паметта към устройство (екран) → `std::cout` (character output), оператор `<<`.

```cpp
#include <iostream>

int main() {
    int age;
    double height;

    std::cout << "Enter age and height: ";
    std::cin >> age >> height;          // въвеждане на две стойности една след друга

    std::cout << "Age: " << age << '\n'
              << "Height: " << height << std::endl;
    return 0;
}
```

- `>>` пропуска празните символи (интервали, табулации, нови редове) – няма значение дали стойностите са на един ред или на няколко.
- Операторите се „навързват“ (chaining): `std::cin >> a >> b >> c;`.
- Нов ред: `'\n'` или `std::endl`. `std::endl` освен това изпразва буфера (flush), затова е малко по-бавен.

Често използвани **escape последователности** (escape sequences):

| Запис | Значение |
| :---: | :------- |
| `\n` | нов ред |
| `\t` | табулация |
| `\\` | обратна наклонена черта `\` |
| `\"` | кавички в низ |
| `\'` | апостроф в символ |

### Форматиране на реални числа

```cpp
#include <iostream>
#include <iomanip> // std::setprecision, std::fixed

int main() {
    double x = 3.14159;
    std::cout << x << '\n';                                     // 3.14159
    std::cout << std::fixed << std::setprecision(2) << x << '\n'; // 3.14
}
```

> [!WARNING]
> Ако въведете стойност от грешен тип (напр. буква, когато се очаква `int`), `std::cin` изпада в състояние на грешка и **следващите четения не се изпълняват**. В задачите приемаме, че входът е коректен.

## 5. Променливи и примитивни типове данни

**Променлива** (variable) е именувано място в паметта, което пази стойност от определен **тип** (type). Типът определя колко памет се заделя, какви стойности може да пази и какви операции са позволени.

```cpp
<тип> <име> = <начална стойност>;
```

```cpp
int count = 50;           // цяло число
double pi = 3.14159;      // реално число
bool isStudent = true;    // истина / лъжа
char grade = 'A';         // един символ (в единични кавички!)
float weight = 72.5f;     // f-суфикс → литерал от тип float
const int DAYS_IN_WEEK = 7; // константа – не може да се променя
```

### Основни типове

| Тип | Типичен размер | Стойности (типично) | Пример |
| :-- | :------------: | :------------------ | :----- |
| `bool` | 1 байт | `true` / `false` | `bool ok = true;` |
| `char` | 1 байт | −128 … 127 (символ по ASCII код) | `char c = 'a';` |
| `short` | 2 байта | −32 768 … 32 767 | `short s = 1000;` |
| `int` | 4 байта | ≈ −2.1·10⁹ … 2.1·10⁹ | `int n = 42;` |
| `long` | 4 или 8 байта | зависи от платформата | `long l = 42L;` |
| `long long` | 8 байта | ≈ ±9.2·10¹⁸ | `long long big = 9000000000LL;` |
| `float` | 4 байта | ~7 значещи цифри | `float f = 1.5f;` |
| `double` | 8 байта | ~15–16 значещи цифри | `double d = 1.5;` |

- Пред целочислените типове може да стои `unsigned` – само неотрицателни стойности с двойно по-голям максимум (напр. `unsigned int`: 0 … 4 294 967 295).
- Стандартът гарантира само минимални размери и `1 == sizeof(char) <= sizeof(short) <= sizeof(int) <= sizeof(long) <= sizeof(long long)`. Например `long` е 4 байта на Windows и 8 байта на 64-битов Linux/macOS.
- По подразбиране за реални числа ползваме `double`.

### `sizeof`

Операторът `sizeof` връща размера на тип или израз **в байтове**:

```cpp
#include <iostream>

int main() {
    std::cout << "bool: " << sizeof(bool) << '\n';
    std::cout << "char: " << sizeof(char) << '\n';
    std::cout << "int: " << sizeof(int) << '\n';
    std::cout << "long long: " << sizeof(long long) << '\n';
    std::cout << "double: " << sizeof(double) << '\n';

    int x = 5;
    std::cout << "x: " << sizeof(x) << '\n'; // може и с променлива/израз
}
```

### Символи и ASCII таблица

`char` пази **число** – кода на символа по [ASCII таблицата](https://www.asciitable.com/). Затова с `char` може да се смята:

```cpp
char c = 'A';
int code = c;                    // 65
char next = c + 1;               // 'B'
char lower = c + ('a' - 'A');    // 'a'  (малките букви са с 32 след главните)
int digit = '7' - '0';           // 7    (символ-цифра → число)
```

> [!TIP]
> Не е нужно да помните кодовете. Важното е, че `'0'..'9'`, `'a'..'z'` и `'A'..'Z'` са **последователни** – затова `'7' - '0' == 7` и `'a' + 2 == 'c'`.

### Имена на променливи (identifiers)

- **Могат** да съдържат малки и главни латински букви, цифри и `_`.
- **Не могат** да започват с цифра, да съдържат интервали или да са запазени думи (`int`, `return`, `double`, …).
- Избирайте смислени имена: `secondsInDay`, а не `s1`. Константите обикновено се пишат с главни букви: `MAX_SIZE`.

> [!WARNING]
> Неинициализирана локална променлива съдържа „боклук“ (произволна стойност). Четенето ѝ е **недефинирано поведение** (undefined behaviour). Винаги задавайте начална стойност или я прочитайте с `std::cin`, преди да я използвате.

### Блок и област на видимост (scope)

Променлива, декларирана в блок `{ }`, съществува само до края на този блок:

```cpp
#include <iostream>

int main() {
    int x = 10;
    {
        int y = 20;
        std::cout << x + y << '\n'; // 30 – x се вижда и във вътрешния блок
    }
    // std::cout << y;  // грешка при компилация: y не съществува тук
}
```

## 6. Преобразуване на типове (type conversion)

### Неявно (implicit)

Компилаторът сам преобразува стойността към нужния тип.

```cpp
int n = 4;
double m = n;          // 4.0  – без загуба на информация

double pi = 3.99;
int whole = pi;        // 3    – дробната част се ОТРЯЗВА (не се закръгля!)

bool b1 = 5;           // true – всяко ненулево число е true
bool b2 = 0;           // false
int fromBool = true;   // 1

char c = 'A';
int ascii = c;         // 65
```

В аритметичен израз с различни типове „по-малкият“ се повдига към „по-големия“: `int + double → double`, `char + int → int`.

### Явно (explicit)

```cpp
int a = 7, b = 2;
double r1 = a / b;                      // 3.0 – делението е целочислено, ПОСЛЕ се преобразува
double r2 = static_cast<double>(a) / b; // 3.5 – C++ стил (препоръчително)
double r3 = (double)a / b;              // 3.5 – C стил
double r4 = a * 1.0 / b;                // 3.5 – трик с умножение по 1.0
```

> [!WARNING]
> `static_cast<double>(a / b)` **не** помага – делението вече е станало целочислено и резултатът е `3.0`. Преобразувайте операнд, не резултата.

### Препълване (overflow)

Всеки тип има граници. При надхвърлянето им:

```cpp
unsigned int u = 0;
u = u - 1;            // 4294967295 – за unsigned се „завърта“ (по модул 2^32)

int big = 2147483647;
// big + 1           // препълване на signed тип → недефинирано поведение!
long long safe = 2147483647LL + 1; // 2147483648 – ползвайте по-голям тип
```

> [!TIP]
> Инициализацията с фигурни скоби забранява стесняващи преобразувания: `int x{3.7};` е грешка при компилация, докато `int x = 3.7;` тихо дава `3`.

## 7. Оператори

### Аритметични оператори

| Оператор | Значение | Пример | Резултат |
| :------: | :------- | :----: | :------: |
| `+` | събиране | `5 + 2` | `7` |
| `-` | изваждане | `5 - 2` | `3` |
| `*` | умножение | `5 * 2` | `10` |
| `/` | деление | `5 / 2` | `2` |
| `%` | остатък от деление (modulo) | `5 % 2` | `1` |

#### Целочислено деление и `%`

- Ако **и двата** операнда на `/` са цели, резултатът е **цял** – дробната част се отрязва (към нулата): `7 / 2 == 3`, `-7 / 2 == -3`.
- Достатъчно е **един** операнд да е реален, за да е делението реално: `7 / 2.0 == 3.5`.
- `%` работи **само с цели числа**; `5.5 % 2` е грешка при компилация.
- Знакът на `a % b` съвпада със знака на `a`: `-7 % 3 == -1`, `7 % -3 == 1`.
- Деление (и `%`) на 0 при цели числа е **недефинирано поведение** – програмата обикновено „гърми“.

#### Работа с цифрите на число

Комбинацията от `/ 10` и `% 10` е ключова за много задачи:

```cpp
int n = 4729;
int last = n % 10;            // 9   – последна цифра
int withoutLast = n / 10;     // 472 – махаме последната цифра
int tens = n / 10 % 10;       // 2   – цифра на десетиците
int hundreds = n / 100 % 10;  // 7
int first = n / 1000;         // 4   – за четирицифрено число
int lastTwo = n % 100;        // 29  – последните две цифри
```

#### Проверка за делимост и четност

```cpp
int n = 14;
bool isEven = n % 2 == 0;     // true
bool divBy7 = n % 7 == 0;     // true
```

### Оператори за присвояване

| Оператор | Пример | Еквивалентно на |
| :------: | :----: | :-------------: |
| `=` | `m = 10` | – |
| `+=` | `m += 10` | `m = m + 10` |
| `-=` | `m -= 10` | `m = m - 10` |
| `*=` | `m *= 10` | `m = m * 10` |
| `/=` | `m /= 10` | `m = m / 10` |
| `%=` | `m %= 10` | `m = m % 10` |

> [!NOTE]
> `=` е **присвояване**, а `==` е **сравнение**. Честа грешка е да се объркат.

### Инкрементиране и декрементиране (`++`, `--`)

```cpp
int a = 5;
int b = ++a; // префиксен (prefix): първо увеличава, после връща → a = 6, b = 6

int c = 5;
int d = c++; // постфиксен (postfix): връща старата стойност, после увеличава → c = 6, d = 5
```

Аналогично за `--`. Префиксният вариант връща самата променлива (lvalue), а постфиксният – временно копие на старата стойност (rvalue).

> [!NOTE]
> **lvalue** – израз, който означава място в паметта (напр. променлива) и може да стои отляво на `=`. **rvalue** – временна стойност (литерал, резултат от `x + 5`), която не може да се присвоява: `x + 5 = 3;` е грешка.

### Оператори за сравнение

Връщат `bool` (`true`/`false`; при отпечатване – `1`/`0`).

| Оператор | Значение | Пример | Резултат |
| :------: | :------- | :----: | :------: |
| `<` | по-малко | `1 < 2` | `true` |
| `>` | по-голямо | `1 > 2` | `false` |
| `<=` | по-малко или равно | `1 <= 2` | `true` |
| `>=` | по-голямо или равно | `2 >= 2` | `true` |
| `==` | равно | `1 == 2` | `false` |
| `!=` | различно | `1 != 2` | `true` |

> [!WARNING]
> Не сравнявайте реални числа с `==`: `0.1 + 0.2 == 0.3` е `false` заради грешки при закръгляне. Сравнявайте разликата с малка константа: `std::fabs(a - b) < 1e-9` (от `<cmath>`).

### Логически оператори

| Оператор | Значение | Пример | Резултат |
| :------: | :------- | :----: | :------: |
| `&&` | логическо „И“ | `(5 < 2) && (5 > 3)` | `false` |
| `\|\|` | логическо „ИЛИ“ | `(5 < 2) \|\| (5 > 3)` | `true` |
| `!` | логическо „НЕ“ | `!(5 < 2)` | `true` |

| `A` | `B` | `A && B` | `A \|\| B` | `!A` |
| :-: | :-: | :------: | :--------: | :--: |
| false | false | false | false | true |
| false | true | false | true | true |
| true | false | false | true | false |
| true | true | true | true | false |

**Съкратено оценяване** (short-circuit evaluation): `&&` и `||` оценяват операндите отляво надясно и спират, щом резултатът е ясен. Така `(b != 0) && (a / b > 1)` е безопасно – при `b == 0` делението изобщо не се изпълнява.

Още без `if` можем да получим `1`/`0` като резултат:

```cpp
int x;
std::cin >> x;
std::cout << (x >= 10 && x <= 99) << '\n'; // 1, ако x е двуцифрено положително число
```

### Приоритет и асоциативност

Всеки оператор има **приоритет** (precedence) – кой се изпълнява първи, и **асоциативност** (associativity) – в каква посока се групират оператори с еднакъв приоритет. Опростена таблица (от най-висок към най-нисък):

| Приоритет | Оператори | Асоциативност |
| :-------: | :-------- | :------------ |
| 1 | `()` групиране, `a++`, `a--` (постфиксни) | → |
| 2 | `++a`, `--a`, унарни `+`, `-`, `!`, `(type)`, `sizeof` | ← |
| 3 | `*`, `/`, `%` | → |
| 4 | `+`, `-` | → |
| 5 | `<<`, `>>` | → |
| 6 | `<`, `<=`, `>`, `>=` | → |
| 7 | `==`, `!=` | → |
| 8 | `&&` | → |
| 9 | `\|\|` | → |
| 10 | `=`, `+=`, `-=`, `*=`, `/=`, `%=` | ← |

```cpp
int r1 = 2 + 3 * 4;      // 14, не 20
int r2 = (2 + 3) * 4;    // 20
int r3 = 20 / 2 * 5;     // 50 – отляво надясно: (20 / 2) * 5
int a, b;
a = b = 5;               // присвояването е отдясно наляво: a = (b = 5)
```

> [!WARNING]
> `<<` има **по-висок** приоритет от сравненията и логическите оператори. Затова
> `std::cout << a == b;` и `std::cout << x > 0 && y > 0;` не правят това, което очаквате (или не се компилират).
> **Винаги слагайте скоби** около израза, който отпечатвате: `std::cout << (a == b);`.

Пълна таблица: [cppreference – C++ Operator Precedence](https://en.cppreference.com/w/cpp/language/operator_precedence).

> [!TIP]
> Когато се колебаете за приоритета – сложете скоби. Кодът става по-четим и за вас, и за проверяващия.

## 8. Чести грешки

| Грешка | Пример | Как да се избегне |
| :----- | :----- | :---------------- |
| Липсва `;` | `int x = 5` | Внимавайте за съобщението *expected ';'* – обикновено сочи **следващия** ред. |
| Целочислено деление | `double avg = (a + b) / 2;` | `(a + b) / 2.0` |
| `%` с реални числа | `5.5 % 2` | `%` е само за цели типове. |
| Неинициализирана променлива | `int sum; sum += x;` | `int sum = 0;` |
| `=` вместо `==` | `x = 5` в израз за сравнение | Сравнението е `==`. |
| Препълване | `int big = 50000 * 50000;` | Ползвайте `long long` и литерал `50000LL`. |
| Липсват скоби при извеждане | `std::cout << a < b;` | `std::cout << (a < b);` |
| Двойни кавички за символ | `char c = "a";` | Символ – `'a'`, низ – `"a"`. |

## Какво ще отпечата?

**1.**

```cpp
#include <iostream>

int main() {
    int a = 5;
    a + 5;
    std::cout << a;
}
```

<details><summary>Отговор</summary>

`5`. Изразът `a + 5` се пресмята, но резултатът не се записва никъде (компилаторът дава предупреждение). За промяна трябва `a += 5;`.
</details>

**2.**

```cpp
int a = 5;
double b = 5;
std::cout << a / 2 << ' ' << b / 2;
```

<details><summary>Отговор</summary>

`2 2.5` – `a / 2` е целочислено деление, `b / 2` е реално.
</details>

**3.**

```cpp
double a = 4.9, b = 5.5;
int sum = a + b;
int bToInt = b;
int sum2 = a + bToInt;
std::cout << sum << ' ' << sum2;
```

<details><summary>Отговор</summary>

`10 9`. `4.9 + 5.5 = 10.4` → `10`; `bToInt = 5`; `4.9 + 5 = 9.9` → `9`. Дробната част се отрязва, не се закръгля.
</details>

**4.** Ще се компилира ли?

```cpp
double d = 4.5;
std::cout << d % 2;
```

<details><summary>Отговор</summary>

Не. Операторът `%` работи само с целочислени типове. (Има функция `std::fmod` от `<cmath>` за реални числа.)
</details>

**5.**

```cpp
std::cout << 7 / 2 * 2.0 << ' ' << 7 / 2.0 * 2;
```

<details><summary>Отговор</summary>

`6 7`. Отляво надясно: `7 / 2 = 3` (целочислено), `3 * 2.0 = 6`; във втория израз `7 / 2.0 = 3.5`, `3.5 * 2 = 7`.
</details>

**6.**

```cpp
int a = 5;
int b = a++ + 10;
int c = ++a * 2;
std::cout << a << ' ' << b << ' ' << c;
```

<details><summary>Отговор</summary>

`7 15 14`. `a++` връща 5 (после `a = 6`) → `b = 15`; `++a` прави `a = 7` и връща 7 → `c = 14`.
</details>

**7.**

```cpp
char ch = 'A';
std::cout << ch + 1 << ' ' << static_cast<char>(ch + 1) << ' ' << '7' - '0';
```

<details><summary>Отговор</summary>

`66 B 7`. `ch + 1` е от тип `int` (65 + 1), затова се отпечатва число; след преобразуване към `char` – буква.
</details>

**8.**

```cpp
std::cout << -7 / 2 << ' ' << -7 % 2 << ' ' << 7 % -2;
```

<details><summary>Отговор</summary>

`-3 -1 1`. Делението отрязва към нулата, а знакът на остатъка съвпада със знака на делимото.
</details>

**9.**

```cpp
std::cout << 1 + 2 * 3 % 4 - 5 / 2;
```

<details><summary>Отговор</summary>

`1`. `2 * 3 = 6`, `6 % 4 = 2`, `5 / 2 = 2` → `1 + 2 - 2 = 1`.
</details>

**10.**

```cpp
int x = 10, y = 3;
std::cout << x / y << ' ' << (double)x / y << ' ' << (double)(x / y);
```

<details><summary>Отговор</summary>

`3 3.33333 3`. В третия случай първо се дели целочислено, после резултатът `3` се преобразува в `3.0` (отпечатва се като `3`).
</details>

**11.** Какво ще отпечата и защо?

```cpp
int a = 1, b = 2, c = 3, d = 4;
std::cout << ((b - a) == (c - b)) && ((c - b) == (d - c));
```

<details><summary>Отговор</summary>

`1` – но **по грешна причина**. Заради приоритета компилаторът го чете като `(std::cout << ((b - a) == (c - b))) && (...)`. Отпечатва се само първото сравнение, а `&&` се прилага върху резултата от `cout`. Например за `1 2 3 5` ще се отпечата пак `1`, въпреки че числата не образуват прогресия. Правилно: `std::cout << (((b - a) == (c - b)) && ((c - b) == (d - c)));`.
</details>

**12.**

```cpp
int a = 5, b = 4, c = 0;
std::cout << a / (!c) + b / (!a);
```

<details><summary>Отговор</summary>

Компилира се, но по време на изпълнение има **деление на нула**: `!c` е `1`, а `!a` е `0` (всяко ненулево число е `true`, отрицанието му – `false`). Недефинирано поведение – програмата обикновено се срива.
</details>

**13.**

```cpp
int a = 5, b = 0;
std::cout << ((b != 0) && (a / b));
```

<details><summary>Отговор</summary>

`0`. Заради съкратеното оценяване `b != 0` е `false` и `a / b` изобщо не се изчислява – няма деление на нула.
</details>

**14.**

```cpp
std::cout << sizeof(char) << ' ' << sizeof('a' + 1) << ' ' << sizeof(5.0f);
```

<details><summary>Отговор</summary>

Типично `1 4 4`. `'a' + 1` е от тип `int` (char се повдига до int), а `5.0f` е `float`.
</details>

**15.**

```cpp
unsigned int u = 0;
u = u - 1;
bool flag = 42;
std::cout << u << ' ' << flag << ' ' << true + true;
```

<details><summary>Отговор</summary>

`4294967295 1 2` (при 4-байтов `unsigned int`). Беззнаковите типове се „завъртат“; ненулево число става `true`; при аритметика `true` е `1`.
</details>
