## Задачи

### Задача 1

Въвежда се цяло число. Да се изведе `Even`, ако числото е четно, и `Odd`, ако е нечетно.

**Вход:**

```
7
```

**Изход:**

```
Odd
```

**Вход:**

```
-4
```

**Изход:**

```
Even
```

### Задача 3

### Задача 4

Двама играчи играят на камък, ножица, хартия. Въвеждат се два символа – ходът на първия и ходът на втория играч. Символът `r` или `R` означава камък, `p` или `P` – хартия, а `s` или `S` – ножица. Камъкът бие ножицата, ножицата бие хартията, а хартията бие камъка. Да се изведе `Player 1 wins`, `Player 2 wins` или `Draw`.

**Вход:**

```
r S
```

**Изход:**

```
Player 1 wins
```

**Вход:**

```
s r
```

**Изход:**

```
Player 2 wins
```

**Вход:**

```
P p
```

**Изход:**

```
Draw
```

### Задача 5

Въвеждат се три цели числа – ъгли в градуси. Да се провери дали съществува триъгълник с такива ъгли. Ако не съществува, да се изведе `Invalid triangle`. Ако съществува, да се изведе видът му: `Acute` (остроъгълен), `Right` (правоъгълен) или `Obtuse` (тъпоъгълен).

<details>
<summary>Предупреждение</summary>

Ъгъл 0 е невалиден, дори ако сборът на трите ъгъла е 180. Не забравяйте да го проверите при валидацията.
</details>

**Вход:**

```
60 60 60
```

**Изход:**

```
Acute
```

**Вход:**

```
90 45 45
```

**Изход:**

```
Right
```

**Вход:**

```
120 30 30
```

**Изход:**

```
Obtuse
```

**Вход:**

```
100 50 40
```

**Изход:**

```
Invalid triangle
```

### Задача 6

Въвеждат се координатите на долния ляв и след това на горния десен връх на правоъгълник, чиито страни са успоредни на координатните оси. След това се въвеждат координатите на трета точка. Всички координати са реални числа. Да се изведе `Inside`, ако точката е вътре в правоъгълника, `On the border`, ако е върху някоя от страните му, и `Outside`, ако е извън него.

**Вход:**

```
1 1 5 4
3 2
```

**Изход:**

```
Inside
```

**Вход:**

```
1 1 5 4
5 2.5
```

**Изход:**

```
On the border
```

**Вход:**

```
0 0 2 2
3 1
```

**Изход:**

```
Outside
```

### Задача 13

Въвеждат се неотрицателни цели числа, докато не се въведе отрицателно число. Отрицателното число служи само за край и не е част от редицата. Да се изведе поредният номер на най-малкото въведено число, като номерацията започва от 1. Ако най-малкото число се среща няколко пъти, да се изведе номерът на последното му срещане. Гарантирано е, че преди отрицателното число е въведено поне едно число.

**Вход:**

```
5 3 8 3 9 -1
```

**Изход:**

```
4
```

**Вход:**

```
7 -5
```

**Изход:**

```
1
```

### Задача 14

Разширете играта от задача 4, така че да се играе до определен брой точки.

Първо се въвежда цяло число `maxScore`. Ако то не е положително, да се изведе `Invalid max score` и да се въведе отново, докато не бъде въведена валидна стойност.

След това играчите играят рунд след рунд, като във всеки рунд се въвеждат ходовете на двамата играчи. Ако някой от ходовете не е валиден символ, да се изведе `Invalid move` и рундът да се изиграе отново. Победителят в рунда получава точка, а при равенство никой не получава точка. След всеки валиден рунд да се изведе текущият резултат във формат `Score: X - Y`.

Когато някой от играчите достигне `maxScore` точки, да се изведе `Player 1 wins the game!` или `Player 2 wins the game!` и програмата да приключи.

**Вход:**

```
0
2
r s
p p
x r
s p
```

**Изход:**

```
Invalid max score
Score: 1 - 0
Score: 1 - 0
Invalid move
Score: 2 - 0
Player 1 wins the game!
```
