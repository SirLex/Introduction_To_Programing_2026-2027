## Задачи

### Задача 1

Напишете функции `myMin(...)` и `myMax(...)`, които връщат съответно по-малкото и по-голямото от две цели числа.

```
myMin(3, 7)    ->  3
myMin(10, -2)  ->  -2
myMax(3, 7)    ->  7
myMax(10, -2)  ->  10
```

### Задача 2

Напишете функция `myAbs(...)`, която връща абсолютната стойност на цяло число.

```
myAbs(-5)  ->  5
myAbs(7)   ->  7
```

### Задача 3

Напишете функция `mySwap(...)`, която разменя стойностите на две целочислени променливи.

```
a = 2005, b = 2007  ->  a = 2007, b = 2005
```

### Задача 4

Напишете функция `myPow(double base, int exp)`, която връща `base` на степен `exp`. Ако `exp` е отрицателно, резултатът е реципрочен: 1 / base^|exp|. Приемете, че при отрицателно `exp` основата `base` е различна от 0.

```
myPow(2, 3)   ->  8
myPow(2, -2)  ->  0.25
myPow(5, 0)   ->  1
```

### Задача 5

Напишете функция `geometricProgression(int start, int ratio, unsigned int n)`, която извежда на екрана първите `n` члена на геометрична прогресия с първи член `start` и частно `ratio`, разделени с интервал.

```
geometricProgression(3, 2, 5)   ->  3 6 12 24 48
geometricProgression(1, -3, 4)  ->  1 -3 9 -27
```

### Задача 6

Напишете функция `reverseNumber(unsigned int n)`, която връща числото, записано с цифрите в обратен ред.

```
reverseNumber(1234)  ->  4321
reverseNumber(1200)  ->  21
```

### Задача 7

Напишете функция, която приема цяло неотрицателно число и връща сбора на цифрите му. Използвайте я в програма, която приема число и пресмята сбора на цифрите му, след това сбора на цифрите на резултата и т.н., докато не се получи едноцифрено число.

**Вход:**

```
9517
```

**Изход:**

```
4
```

Пояснение: 9 + 5 + 1 + 7 = 22, а 2 + 2 = 4.

**Вход:**

**Изход:**

**Вход:**

7

### Задача 9

Напишете функция `nextPrime(int n)`, която връща най-малкото просто число, по-голямо от `n`.

```
nextPrime(10)  ->  11
nextPrime(13)  ->  17
nextPrime(1)   ->  2
```

### Задача 10

Напишете функция `printByDigitAverage(int m, int n, int k)`, която извежда на екрана всички числа в интервала [m, n] (0 < m < n ≤ 1000000), за които средноаритметичното на цифрите е по-голямо или равно на k (0 < k < 10).

```
printByDigitAverage(10, 50, 6)  ->  39 48 49
```

### Задача 11

Напишете функция, която приема краищата на интервал [a, b] и извежда на екрана всички числа в него, които са равни на сбора от факториелите на цифрите си.

```
Пример: 145 = 1! + 4! + 5!
```

**Вход:**

```
1 200
```

**Изход:**

```
1 2 145
```

### Задача 12

Едно число е число на Армстронг, ако е равно на сбора от цифрите си, всяка повдигната на степен, равна на броя на цифрите му. Напишете функция, която приема краищата на интервал [a, b] и извежда на екрана всички числа на Армстронг в него.

```
Пример: 153 = 1³ + 5³ + 3³
```

**Вход:**

```
100 500
```

**Изход:**

```
153 370 371 407
```

### Задача 13

Напишете функция `permutationNumbers(unsigned int a, unsigned int b)`, която връща дали цифрите на едното число са пермутация на цифрите на другото, тоест дали всяка цифра се среща еднакъв брой пъти в двете числа.

```
permutationNumbers(12321, 21132)  ->  true
permutationNumbers(112, 122)      ->  false
```

### Задача 14

Напишете функция `moveLastDigits(unsigned int a, unsigned int b, unsigned int k)`, която връща числото, получено, като последните `k` цифри на `a` се поставят пред цифрите на `b`. В случай, че `k` надвишава броя на цифрите на `a` нека функцията връща `b`.

```
moveLastDigits(12345, 67, 2)  ->  4567
moveLastDigits(9876, 5, 3)    ->  8765
moveLastDigits(20, 5, 3)      ->  5
```

### Задача 15

Напишете функция `removeDigitAt(unsigned int& num, unsigned int index)`, която премахва цифрата на позиция `index` от числото `num`. Позициите се броят отляво надясно, започвайки от 1. Ако позицията е невалидна, числото не се променя.

```
num = 12345, index = 3  ->  num = 1245
num = 12345, index = 7  ->  num = 12345
num = 120,   index = 1  ->  num = 20
```
